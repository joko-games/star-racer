One file to run, nothing to install: unpack it and start star-racer-client. It plays on the same server as this site, with a gamepad, a keyboard or both. The build is not signed: Windows asks before running it the first time ("More info", then "Run anyway"). On Linux and macOS, the browser version runs the same game, against the same players.

OR RUN YOUR OWN SERVER
Server for Windows64-bit · .zip Server for Linux64-bit · .tar.gz

The same server this site runs, with the circuits and the car's tuning in its data folder. Unpack it and start star-racer-server from inside the folder; it listens on port 8080 of this computer only. In the downloaded game, SETTINGS, then SERVER: type 127.0.0.1.

To race friends on the same network, start it with --listen 0.0.0.0, and let them type ws:// and your computer's address with the port, such as ws://192.168.1.20:8080. Over the internet, the port has to be opened on your router. Only the downloaded game can join such a server: a page served over HTTPS, like this one, may not reach a plain ws:// address. Accounts, ranked ratings and experience are kept in files beside it; --help lists the options.
